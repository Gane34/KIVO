# Literature Audit: Padova T2D Simulator

## Audit scope and access

The audit checked bibliographic and abstract records, publisher landing/PDF/supplement routes, Europe PMC full-text and data metadata, and public GitHub repository search. Access was checked on 2026-10-13. These checks verify the facts below, but do not constitute a full-text scientific review.

**Original publication (R2).** Visentin R, Cobelli C, Dalla Man C. “The Padova Type 2 Diabetes Simulator from Triple-Tracer Single-Meal Studies: In Silico Trials Also Possible in Rare but Not-So-Rare Individuals.” *Diabetes Technology & Therapeutics*. 2020;22(12):892-903. DOI: [10.1089/dia.2020.0110](https://doi.org/10.1089/dia.2020.0110); PMID: [32324063](https://pubmed.ncbi.nlm.nih.gov/32324063/); [publisher record](https://journals.sagepub.com/doi/10.1089/dia.2020.0110); [Europe PMC record](https://europepmc.org/article/MED/32324063).

- The publisher marks the article as restricted access. Its accessible abstract reports model structure and summary results, not the full equations or parameter table.
- Europe PMC records it as not open access, not in PMC, and with no linked supplementary file or data record (`hasSuppl=N`, `hasData=N`).
- The publisher supplementary route returned article/abstract content but no separate supplementary file was exposed in the route checked. Publisher full-text XML/PDF routes did not provide extractable full text in this audit environment. This is an access limitation of the checked routes, not proof that no institutionally accessible copy exists.
- GitHub repository searches for the simulator name and Padova/T2D terms returned no matching T2D model repository. GitHub code search by DOI returned HTTP 401, so code search was not exhaustive. No verified source-code release was located; this is not proof that one does not exist elsewhere.

## Related methods evidence

- **R1 — Dalla Man C, Rizza RA, Cobelli C.** “Meal Simulation Model of the Glucose-Insulin System.” *IEEE Transactions on Biomedical Engineering*. 2007;54(10):1740-1749. DOI: [10.1109/TBME.2007.893506](https://doi.org/10.1109/TBME.2007.893506); PMID: [17926672](https://pubmed.ncbi.nlm.nih.gov/17926672/). The abstract describes subsystem decomposition and a triple-tracer meal dataset used to estimate major glucose and insulin fluxes; the strategy was also applied to a smaller T2D database. It is a model-development precedent, not the complete 2020 T2D specification.
- **R6 — Basu R, Di Camillo B, Toffolo G, et al.** “Use of a novel triple-tracer approach to assess postprandial glucose metabolism.” *American Journal of Physiology-Endocrinology and Metabolism*. 2003;284(1):E55-E69. DOI: [10.1152/ajpendo.00190.2001](https://doi.org/10.1152/ajpendo.00190.2001); PMID: [12485809](https://pubmed.ncbi.nlm.nih.gov/12485809/). Its abstract describes a meal [1-13C]glucose tracer plus patterned intravenous tracers designed to reduce non-steady-state error when estimating meal glucose appearance and endogenous glucose production. This supports the measurement approach, not automatic validity of any reduced model.
- **R7 — Van Cauter E, Mestrez F, Sturis J, Polonsky KS.** “Estimation of insulin secretion rates from C-peptide levels. Comparison of individual and standard kinetic parameters for C-peptide clearance.” *Diabetes*. 1992;41(3):368-377. DOI: [10.2337/diab.41.3.368](https://doi.org/10.2337/diab.41.3.368); PMID: [1551497](https://pubmed.ncbi.nlm.nih.gov/1551497/). The abstract describes insulin secretion estimation by C-peptide kinetic modeling and a comparison of standard and individually measured kinetics. C-peptide is informative when paired with an explicit kinetic method; concentration alone is not a secretion rate.

## Audit conclusion

Only the component list, total equation/parameter counts, identification approach, high-level cohort design, output analytes, and abstract-level summary results can presently be reported for R2. The complete published model cannot be reproduced from information accessible in this audit. No Padova state, equation, numeric parameter, or code has been copied or reverse-engineered. Obtain and review the full text, supplements if any, and any author-provided implementation before designing a fidelity benchmark.
